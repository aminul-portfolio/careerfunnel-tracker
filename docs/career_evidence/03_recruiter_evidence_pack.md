## Project Positioning Summary

CareerFunnel Tracker is a Django/Python analytics and AI application workflow project that structures job-search activity into application records, funnel-stage metrics, source-performance reporting, data-quality warnings, skill-gap evidence, application-readiness checks, and controlled AI-assisted decision support.

The project combines a deterministic analytics core with a controlled AI engineering layer. Implemented AI evidence includes a fail-closed LLM provider boundary, offline evaluation harnesses, claim-safety controls, small private-corpus RAG/retrieval evaluation, bounded read-only tool-calling, controlled live-provider integration evidence, and human-in-the-loop review.

Claim-safe boundaries remain explicit:

- AI-assisted outputs are advisory and human-reviewed.
- Application actions remain manual.
- No autonomous job application or auto-apply is implemented.
- No autonomous-agent claim is made.
- Small private-corpus RAG is not presented as enterprise RAG.
- No production vector database is claimed.
- Live-provider evidence is limited to a controlled synthetic one-call canary and is not production reliability evidence.
- No Gmail/Calendar automation, scraping, production SaaS usage, production customers, or commercial product claim is made.

Verified baseline: **3,012 passing tests as of Sprint 124B**, with Ruff, Django system checks, migration-drift checks, browser UAT, and GitHub Actions Django CI #241 passing on the Sprint 124B merge commit.
